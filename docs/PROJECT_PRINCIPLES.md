# Project principles

The code is replaceable. These ideas are the invariant core.

1. **Data before product surface.** Do not optimize a UI around unverified model output.
2. **Evidence before inference.** Every extracted process fact points to a source release, document, location, and checksum.
3. **Offline-first operation.** Collection can touch the internet; normalization, curation, training, evaluation, and serving run from frozen local artifacts.
4. **Scale is not stage.** A patent's gram or kilogram example and a program's clinical phase are separate observations with separate provenance.
5. **Same drug is not similar drug.** Exact structure, connectivity, active moiety, salt/solvate/prodrug, analogue, and name-only links remain distinct.
6. **Continuous facts before categorical labels.** Store mass, volume, moles, yield, purity, temperature, pressure, and time. Derive versioned bands later.
7. **Machine extraction proposes; review decides.** Training labels require accepted evidence, not a model's own unreviewed output.
8. **No leakage disguised as performance.** Patent families, active moieties, near-duplicate procedures, and time are explicit split groups.
9. **Licensing is record-level provenance.** A source's permission and attribution travel with derived evidence and exports.
10. **Uncertainty is data.** Unknown, conflicting, predicted, generic, and unperformed disclosures are represented rather than silently coerced.

## Scientific boundary

This project is a research and decision-support system. Patent disclosure can suggest that a process was contemplated or reported; it does not independently establish reproducibility, safety, regulatory acceptability, freedom to operate, or commercial readiness. High-stakes process decisions require qualified scientific, legal, safety, and regulatory review.
